# Contributing

Thanks for helping improve NextPage. Focused bug reports and pull requests are welcome.

## Before starting

1. Search existing issues for related work.
2. Open an issue before making a large behavioral or interface change.
3. Keep navigation conservative. NextPage should refuse uncertain links instead of opening unrelated pages.

## Development

1. Load this folder as an unpacked extension in a Chromium based browser.
2. Reload the extension after changing its files.
3. Refresh open website tabs after reloading the extension.
4. Run `node --test tests/*.test.js` before submitting a pull request.

## Pull requests

Describe the problem, the intended behavior, and how you verified the change. Add or update tests whenever behavior changes.
