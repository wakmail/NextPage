# NextPage

NextPage is a Chrome extension for moving through paginated websites and controlling scroll position with keyboard shortcuts.

## Features

1. Find and open next or previous page links.
2. Scroll instantly to the top or bottom with a shortcut.
3. Remember your position on recently visited pages.
4. Choose whether navigation restores your position, moves to the top, moves to the bottom, or leaves the page unchanged.
5. Change every shortcut from the Chrome extension shortcut settings.
6. Adjust smooth scroll animation from instant to a gentle four seconds. New installations default to a quarter second, and the Reset button restores that value.
7. Show an optional movable glass page bar with safe Previous and Next actions.
8. Open a nearby page grid or type a page number directly when the site exposes a reliable page pattern.
9. Reset the floating bar to the bottom center from the extension popup.

## Install locally

1. Open `chrome://extensions` in Chrome.
2. Enable Developer mode.
3. Choose Load unpacked.
4. Select this `NextPage` folder.

## Default shortcuts

| Action | Shortcut |
| --- | --- |
| Next page | Alt plus Shift plus Right Arrow |
| Previous page | Alt plus Shift plus Left Arrow |
| Scroll to top | Alt plus Shift plus Up Arrow |
| Scroll to bottom | Alt plus Shift plus Down Arrow |

Use the Change keyboard shortcuts link in the popup to assign different keys.

Chrome blocks extensions on internal browser pages and the Chrome Web Store. NextPage works on normal web pages that use HTTP or HTTPS.
